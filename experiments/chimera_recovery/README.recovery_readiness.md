`recovery_readiness.py inspect --request <new pinned request> --out <new receipt>`
authenticates actual manifest/receipt/file edges and compares all 938 final
audio/speech index rows to their original native members. It independently sums
the recorded assistant/scalar denominators. Missing local tensors remain named
file/mount dependencies. Metadata traversal cannot certify tensor reconstruction,
an accepted checkpoint, useful intelligence or production availability.

The request schema is `chimera_recovery.target_preparation_request.v1`. Each native
lane needs either an actual file pin or a concrete absent-data reason. Executing
helpers are pinned separately from producer cache helpers. SHA-to-absolute-file
locator maps can find received copies; changed existing files cannot be rescued
by an alias. Producer objects remain unchanged. Relative file edges resolve at
their actual native manifest/receipt directory. The full graph records unavailable
historical/source files instead of inventing locations.

cpu-targets --request <actual namespace request> --role h3 --role geometry
--role image_edit --role audio_ce --role speech_flow --out <fresh proof>` uses the
existing source/tensor validators and CPU reconstruction. It creates no model or
optimizer. The actual producer paths must be mounted, including all source files;
metadata aliases do not monkey-patch production readers. Stage a new request with
the executing source capsule and exact original mounted targets, preserving all
producer bytes. Guided ACE/QIMG retain the original ReadyObjectiveAdapter;
H3 additionally requires full original-source/dual-clock/packer reconstruction.
General full checks for music-code and vision use their native stage preflights.

`combine-preregistration --request ... --selected-preregistration <last exact
image-edit document> --select-established-policy --out <fresh combined.md>`
preserves the frozen body and complete previous amendment as an unchanged prefix,
appends current D3a/c/d contracts and the reproducible root-selected D4 policy,
and emits a separate pinned policy selection. This selects budgets/rates/weights,
not accepted states or absent target files. Exact full replay membership still
requires genuine final native music, vision and text/K3 targets and its selected
source-membership/whole-row-overshoot receipt.

and `recovery_readiness.py` in its source helpers. The dispatcher checks scalar
choices, exact current target/index identity and observed replay counts/weights.
Its actual producing checkpoint rate ledger must independently agree with the
selected per-owner rates after multiplication by 0.3; mismatches refuse before
union optimizer creation. The policy file enters replay/checkpoint/resume pins.

Other objective schemas retain their original guards. Geometry uses its genuine
producer field `sigma_grid`; seals, helper identity and complete source/sigma
coverage remain required. Earlier producer receipts are never relabeled.
