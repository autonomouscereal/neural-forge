# D4 candidate execution, 2026-10-13

`consolidation_dispatch.py` now calls the actual union constructor, native
objective backward functions, one physical AdamW, exact cursor/owner counters,
checkpoint/resume core and immutable replacement writer. It cannot allocate a
runtime, accept earlier stages or register the final model.

Run `python -m experiments.chimera_recovery.consolidation_dispatch preflight
--config <pinned-config.json>` before the explicit `train --config ... --out
<new-directory> [--resume <checkpoint>]` mode. Unknown/missing modes refuse.
Preflight reports `candidate_preflight_passed`, while `production_ready` remains
false: metadata preflight cannot substitute for actual native parity, live
resource authority or evaluation.

The config schema is `chimera_recovery.d4_dispatch_config.v1`, stage `D4`.
It requires the frozen preregistration and selected dated amendment, actual
accepted stages in `consolidation.STAGE_ORDER`, immutable registered D2 native
clone, exact pre-D2 source, authentic complete D2 r64/r32/gain bank binding, final
`D3d_speech_flow` cumulative native/shared-r16 exports, actual replay catalog,
per-owner prior-rate ledger and current helper/streamed-trainer source pins.
The actual checkpoint budgets/configs and producing optimizer base rates are
checked before D4 creates fresh optimizer state. Native compact owners refuse
conflicting contributing rates; separate full banks are never summed.

Replay schema `chimera_recovery.d4_replay.v1` pins global exclusions and actual
sealed native manifests. Every row carries `source_batch_id`, `source_manifest`,
absolute `input`/`target` file pins, unchanged `storage`, original
`source_recovery_group_id`, current global `recovery_group_id`, measured
`supervised_units`, `objective_weight`, and actual active optimizer families.
It binds original cache amendment SHA separately from the selected D4 SHA.
Compatible earlier cache preregistrations must be exact unchanged prefixes of
the selected append-only amendment; producer receipts are not rewritten.

Original budgets remain 2.5M short-text +0.5M long-text +1M Kimi real tokens,
300 distinct pairs each vision/ACE/QIMG/HY3D/H3. Whole-row token overshoot needs
an exact selected dated declaration. Padding, assistant positions and flow
scalar channels do not count as real input-token budget. Guided native pairs
retain the original equal-modality pair mean (`supervised_units=1`), including
unchanged raw-head parameterization and audited parent signs. Vision combines
text KD with feature MSE as one pair; both gradients receive the window weight.
Supervised speech uses canonical sigma and the explicit x0-to-velocity loss.

The selected speech amendment adds every admitted audio/speech CE batch and
every admitted speaking source/sigma pair exactly once. The dispatcher consumes
the independent `chimera_recovery.audio_speech_replay_index.v1` only after full
source reconstruction/seals. It uses current union groups for global exclusion
while retaining original producer group/pins. All existing native validators
run again immediately before backward. Text replay reconstructs IDs, assistant
ownership and exact teacher targets from the actual raw Qwen/Kimi cache; raw
cache verification and authenticated cross-token provenance are mandatory.

Runtime schema `chimera_recovery.d4_allocated_runtime.v1` binds job digest,
allocation group, actual Docker container/image, ordered GPU UUIDs, absolute
interpreter/Torch identity, explicit readonly mounts, root-controller/source
hashes and independently measured host budget. `attest_runtime` validates raw
PG rows, Docker inspection, in-container CUDA evidence and host observations.
The root collects/publishes that evidence; this trainer cannot renew itself.
Every actual Adam step reopens a proof no older than45seconds. Failed/unfinished
allocator CLI responses provide no authority until official labels/PG status
are reconciled. D4 does not inherit D1-specific K3-cache completion rules.

Safety policy remains checkpoint every30minutes/keep2, halt after8 consecutive
nonfinite windows or >20% over100attempts, and quarter-run decode review.
Rejected windows preserve rows, RNG, applied counters and optimizer state.
Wrapper policy is hashed alongside each actual engine checkpoint and survives
resume. Review requires full answers, outcomes, protocol and baseline answers
pinned to the exact trained checkpoint/run. Completing a one-window fixture
also requires review before final export. Final output is a fresh immutable
candidate replacement set, unaccepted and unregistered.

Current blockers are real: no accepted D2 or terminal D3 state exists; the full
audio/speech reconstruction index is pending final source/cache seals; actual
teacher-backed text replay tensors/catalog and full quotas are not supplied;
current-base objective/gradient parity and production RAM/CUDA lease are absent.
New supervised HY3D volume batches require their own audited geometry contract,
canonical sigma versus native progress1−sigma, selected amendment and exact
576:640→320:384 channels. This dispatcher deliberately refuses old guided/planar
HY3D substitutes. Final registered native checkpoint publication/parity and
held-out intelligence/media evaluation remain separate required work.

Tests exercise actual tiny Hybrid forward/streamed gradients, raw signed guided
pair means, distinct x0-to-velocity scaling, a quarter-review stop followed by
bit-identical resumed Adam replay, revoked resource gates and nonfinite retry
without cursor advance. Fixture receipts do not certify real model intelligence.
