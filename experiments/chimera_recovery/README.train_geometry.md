# Distinct supervised geometry candidate, 2026-10-13

`python -m experiments.chimera_recovery.train_geometry preflight --config ...`
checks a source-pinned candidate without opening model weights. Explicit
`train --config ... --out <fresh-directory> [--resume <checkpoint>]` needs
the exact accepted qimg predecessor, cumulative native/shared-r16 exports,
immutable D2 base, source cache, selected numeric amendment, actual objective
parity and fresh root-produced PG/Docker/CUDA authority. It allocates nothing.

The config schema is `chimera_recovery.geometry_stage_config.v1`, stage
`D3b_geometry_supervised_flow`, objective `supervised_geometry_rectified_flow`.
It binds the selected original `recovery_geometry_flow_batches.v1` manifest
and `geometry_amendment` pin. The root-selected amendment must include
`optimizer_scope.optimizer` matching `train_geometry.OPTIMIZER` and
`optimizer_scope.ownership` exactly `['HY3D_unit','type7_bridge',
'type7_emission','shared_r16']`. Native unit/bridge/emission rates are2e-5,
shared-r16 rate1e-4; the type6 image bridge stays frozen. No other trunk weights
are thawed. Seed, native dtype, kernels, one-pass sampling and every helper SHA
are explicit configuration fields. The safety policy is the D4 frozen policy.

The driver loads the original geometry compact tensors through
`GeometryFlowAdapter.bind`, which reconstructs the genuine raw image, prescribed
noise and original ShapeVAE target before every backward. Model inputs contain
only user prefix, raw type6 pixels, type7 time sentinel and noisy latent.
Canonical target is epsilon−clean; the existing raw prediction is negated by
the original source adapter. Native progress1−sigma is routed to the bridge,
while canonical sigma remains separate metadata. There is no endpoint division
or slope conversion in this loss. Only4096latent rows×64emission channels
contribute; image/time rows have zero loss and the native update mask excludes them.
HY3D source positions stay under the `hy3d` key and are never routed into H3.

All shared/native inheritance occurs before census/optimizer construction.
The optimizer has one physical owner per FP32 leaf. Full-depth backward retains
trunk adapter gradients, with no cached lower-stack shortcut. Nonfinite steps
restore RNG, leave source cursor/Adam state unchanged, and halt after8consecutive
skips or>20%over100attempts. Safety checkpoints are rolling30minutes/keep2.
Exact resume verifies budget, identity, physical Adam counters and source cursor.
Quarter-run review requires pinned full answers, outcomes, protocol and baseline
answers on the exact trained checkpoint, including a one-step final run.
Accepted review evidence is checked again on resume. Final complete-stage exports
use the existing full shared-r16/native handoff; outputs remain unaccepted and
unregistered until independent review and native publication.

The current source is eight authored boxes/four sigma pairs per source, with
sixteen held families excluded. This establishes a small supervised source
preparation scope. It does not establish natural-object competence, original
HY3D DINO cross-attention parity, full-parent parity or current-model learning.
The authentic selected amendment retains those explicit false parity flags.
No production training was launched by this implementation.
