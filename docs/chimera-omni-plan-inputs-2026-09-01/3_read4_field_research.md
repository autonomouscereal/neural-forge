## Bottom line
A dense ~27B at Q4 (≈14.3–17.6 GB GGUF) on a 24 GiB card can hold 256k context ONLY if per-token KV is ≤ ~20 KB at Q8 (≈5–6 GiB budget after ~1.5–2 GiB compute/logit buffers). Of the candidate configs, only the 3:1 linear:full hybrids and MLA-hybrids clear that bar at Q8; a 3:1 hybrid whose full layers are GQA-8×128 (or Qwen's GQA-4×256) needs q4_0 KV (4.5 GiB) or a leaner Q4 weight file to fit; all-layer GQA is impossible (34 GiB Q8). The field's 2026 consensus config (Kimi Linear → Kimi K3, GLM-5.3-Flash, Qwen3.8-Next) is 3 KDA/GDN : 1 full layer, fixed 128×128-per-head recurrent state in the linear layers, and NoPE/partial-RoPE on the full layers — and every one of those models is a fresh pretrain, not a conversion (the synthesis doc's own KILL LIST says post-hoc KDA conversion needs finetuning).

## (1) Architectures, exact
**Kimi Linear / KDA** (arXiv 2510.26692; HF config moonshotai/Kimi-Linear-48B-A3B-Instruct): KDA = Gated DeltaNet with per-channel (diagonal) decay; recurrent state per head S_t ∈ R^{d_k×d_v}, d_k=d_v=128 ⇒ 16,384 values/head, constant in sequence length; short depthwise conv kernel 4. 48B-A3B config: hidden 2304, 27 layers, 32 KDA heads (state/layer = 32×128×128 = 524,288 values = 2 MiB f32), full-attn layers [4,8,12,16,20,24,27] = 7 MLA + 20 KDA (3:1), MLA kv_lora_rank 512, qk_rope 64, qk_nope 128, v 128, 32 heads; paper says NoPE on MLA layers; 256 experts top-8; ctx 1,048,576. Paper: 75% KV reduction, 6× decode throughput at 1M, TPOT 1.84 ms vs 11.48 ms for MLA. State-size equivalence I derived: 1 KDA layer (32 heads) = MLA(576)-cache of 910 tokens; K3's 96-head KDA layer = 2,731 tokens of MLA cache.
**Kimi K3** (arXiv 2607.24653; HF moonshotai/Kimi-K3 config): NOT dense — MoE, 2.8T total, **104B activated** (report abstract; vLLM blog's "~50B" is inconsistent), 93 layers, hidden 7168, **69 KDA + 24 MLA** (3:1; full_attn_layers every 4th plus layer 93), 96 heads, KDA head_dim 128 × 96 heads, lower-bounded decay g_min = −5, "Gated MLA" = sigmoid(W_g x) ⊙ output gate, MLA kv_lora_rank 512 / q_lora 1536 / rope 64 / nope 128 / v 128, Block AttnRes (depth-wise attention with learned pseudo-query over RMS-normed block outputs; ~12-layer blocks), 896 experts top-16 + 2 shared (Stable LatentMoE, latent 3584), MXFP4 weights/MXFP8 activations QAT from SFT, ctx 1M. Per MLA layer per token: 576 values ⇒ 24×576 = 13,824 values = 27 KB fp16/token.
**GLM-5.3-Flash** (HF zai-org/GLM-5.3-Flash config; Raschka notes): MoE 320B-A18B, hidden 4096, 45 layers = **34 KDA + 11 MLA/DSA** (full layers at 3,7,…,43), KDA 64 heads × 128 (state/layer 4 MiB f32), MLA kv_lora_rank 512, **qk_rope_head_dim 0, mla_use_nope true** (pure NoPE), qk_nope 256, v 256, 64 heads; DSA indexer top-k 2048, 32 index heads × 128; 288 experts top-8 + 1 shared, first 3 layers dense; mHC 4-stream hyper-connections; ctx 1,048,576. Per full layer per token ≈ 512 latent + ~128 indexer key = 640 values.
**Qwen3.8-Flash-Next** (HF Qwen/Qwen3.8-Flash-Next config, model_type qwen4_exp; LMSYS 2026-08-26): MoE 125B + 51B n-gram table, 6B active, hidden 2560, 48 layers = **36 GDN + 12 QSA** (full_attention_interval 4), GDN 16 key heads / 48 value heads × 128, conv 4; full layers 24 Q heads / **2 KV heads × 256**, partial_rotary_factor 0.25 (64 of 256 dims RoPE); QSA indexer 4 heads × 128, 1 kv head, compress ratio 4, budget 2048; 512 experts top-10; Gated Residual 4-stream; ctx 262,144.
**Qwen3.8-27B (the real dense 27B comparator)** (HF Qwen/Qwen3.8-27B config, qwen3_5 arch): hidden 5120, 64 layers = **48 GDN + 16 gated full attention** (interval 4), GDN 16 k-heads / 48 v-heads × 128 (state/layer 3 MiB f32; 48 layers ≈ 148 MiB fixed), full layers 24 Q / **4 KV heads × 256**, partial_rotary 0.25, FFN 17,408, vocab 248,320, ctx 262,144 native (YaRN to 1M), 1-layer MTP head. 
**Gemma 4 31B** (arXiv 2607.02770; kaitchup): 60 layers, 5:1 ⇒ 50 sliding (window 1024, 16 KV heads × 256) + 10 global (4 KV heads × global_head_dim 512, **values = keys**, pp-RoPE p=0.25); stated global-KV reduction 37.5%; kaitchup computes 20.78 GiB KV at 262k bf16 (counting K and V separately for globals; 10.0 GiB if the engine dedups K-as-V).

## (3) llama.cpp / GGUF status (as of 2026-08-31) and P40
- GATED_DELTA_NET op: PR #19504 merged 2026-03-07 (CPU + CUDA + Metal; Vulkan missing per #20354). `ggml-cuda/gated_delta_net.cu` is **fp32-only, no __CUDA_ARCH__/cc guards, warp-shuffle reductions only, head sizes 16/32/64/128, KDA mode = per-dimension gate (src_g->ne[0]==S_v)**; "TODO: Add chunked kernel" ⇒ prefill is sequential per token. Runs on Pascal by construction.
- Qwen3-Next/3.5/3.6/3.8 (qwen35): supported; Qwen3.8-27B GGUFs shipped by unsloth. Qwen3.8-Flash-Next (qwen4exp): in regression suite, unsloth GGUF exists. Kimi-K3: PR #26185 **merged 2026-08-15** (CPU+CUDA full; Metal/Vulkan per-node fallback; MXFP4 experts repacked; Q2_K ≈ 700 GB). Kimi-Linear: passes regression (0 failures) on master. GLM-5.3-Flash (glm5_next): two competing PRs #27752 (eauchs, opened 2026-08-26) and #27754 (unsloth) both **still open**; require `-fa off`, `NVIDIA_TF32_OVERRIDE=0`, IQ3+; MTP drafts +48% throughput; indexer key cache 2.4× at 64k.
- KV-quant caveats: default CUDA FA kernels only F16/F16, Q4_0/Q4_0, Q8_0/Q8_0, BF16/BF16 (mixed pairs need -DGGML_CUDA_FA_ALL_QUANTS=ON, else silent CPU fallback, issue #24485). Hybrid Qwen3.5-9B: q4_0 KV measured BLEU 1.000 vs f16 (issue #21385, 2026-04-03) — the 24/32 GDN layers absorb noise. DeepSeek-V4 (sparse-indexer MLA): q8_0 K-cache → garbage, keep K f16 (issue #25382, open since 2026-07-07) — expect the same risk for DSA-style layers. Recurrent state must stay f32 (Nemotron 3 Super report: FP16-cast SSM cache → +37–40% verbosity). MLA in llama.cpp stores the 576-dim latent (PR #12227); FA DKQ=576 requires V=512.
- P40 (sm_61, 24 GiB, 346 GB/s, no bf16, fp16 at 1/64 rate): **CUDA 13 removed sm_61 — must build with CUDA 12.8/12.9** (12.9 conflicts with glibc ≥2.41 headers). FA on Pascal → generic tile kernel (no tensor cores). Evidence it works: WSL2 P40 repo runs Qwen3.6-35B-A3B (GDN hybrid) at ~51 tok/s with 128k ctx; 8×P40 rig runs Kimi-K2.5 at 5.85 t/s (discussion #19248); P40 tg128 54.7 t/s vs 3090 158 t/s (discussion #15013). Extrapolated dense-27B-Q4 on P40: ~12–15 t/s short-ctx, ~8–9 t/s at 256k with 8.5 GiB Q8 KV re-read per token; 256k prefill on the order of 15–30 min (sequential GDN kernel + tile FA).

## (4) Closed-form MoE→dense and cross-model alignment
No published training-free method folds ALL experts into one dense FFN. The only full MoE→dense work ("Pruning and Distilling MoE into Dense", arXiv 2605.28207, June 2026: score→select→group→concatenate experts into a dense FFN) needs ~4B-token distillation (+6.3 pp over dense-to-dense pruning, 1.6× faster; Qwen3-30B-A3B, DeepSeek-V2-Lite, GPT-OSS-20B). Closed-form toolkit for partial merging: **MergeMoE** (2510.14436) — output-space merge E'_i(X)=W'_D T1(σ(T2 W'_G X)⊙(T3 W'_U X)), T1 = Q P† (least squares), Theorem 1: optimal weights = relative usage frequencies f_j/Σf_k; 16–40 calibration samples; Qwen3-30B-A3B/Qwen1.5-MoE/DeepSeekMoE. **ExFold** (2608.24938, Aug 2026) — ridge scalar projection s*_{s→t}=Σw_i⟨v_i,u_i⟩/(Σw_i‖v_i‖²+λ), λ=1e-3, 32 seqs × 4096 tok; 50% expert cut keeps 68.50 vs 69.04 baseline (Qwen3-30B-A3B), 97.2% GLM-4.5-Air, 97.68% DeepSeek-V4-Flash. **Sub-MoE** (2506.23266, AAAI 2026) — joint SVD, shared U + frequency-merged V; Mixtral 8→6 experts 96%, 8→4 86%. **PuzzleMoE** (2511.04805) — dual-mask element-wise merge, 128×2048 C4; Mixtral 50%: MMLU 65.7 vs HC-SMoE 49.0. **HC-SMoE** (ICML 2025) — output-clustering merge. Warnings: **REAP** (2510.13999, ICLR 2026) shows pruning beats merging on generative tasks at 50% ("merging introduces irreducible error from loss of routing control"); **HARC** (2606.03391) closed-form Hessian-aware router calibration ((ΣΣ_i)w*=ΣΣ_i w_i) because merged routing diverges on 50% of tokens/layer, 99.98% cumulative over 16 layers; **"Is Retraining-Free Enough?"** (2603.02217) — router calibration is necessary. Cross-model residual alignment: **Orthogonal Procrustes R=UVᵀ from SVD(XᵀY) is the winner** in Atlas-Alignment (2510.27413v2, Apr 2026; 500k train seqs from The Pile; faithfulness GPT-2 24.2, Qwen-3B 24.6, Llama-IT L12 37.2, multi-layer 85.1; beats OLS/CCA/covariance). **Ridge (XᵀX+λI)⁻¹XᵀY, λ=0.01, per head** in Cross-Model KV Transfer (2608.03893, Aug 2026): RoPE stripped before mapping; 500×1024-tok FineWeb-Edu (~128k tok/head); Qwen3 14B→32B R² K 0.56/V 0.32 single source layer → 0.79/0.65 with top-8 source layers; 73–98% accuracy retention on 4 pairs, 42–44% on 2; within-family, matched head geometry only. Model Stitching (2506.06609) fits affine maps with Adam (not closed-form; 180k OpenWebText, SVCCA layer picking). Cautions: Oozeer et al. (2503.04429, ICML 2025) autoencoders beat affine maps across Llama/Qwen/Gemma; negative result (2606.03280) — cos 0.97 linear alignment gave zero functional transfer Pythia-160M→410M.
