## Architecture spec (exact, from code)

**Config (`ChimeraConfig`)**: `vocab_size, hidden_size, intermediate_size, num_layers, num_heads, num_kv_heads, max_sequence_length` required; `block_pattern` (default `("kda","kda","csa","kda","hca")`, kinds ∈ {kda, local, csa, hca, gated_mla}); `residual_mode ∈ {"none","block_attnres"}` (default block_attnres, `attnres_block_size=12`); `force_final_gated_mla`; `feed_forward_kind: Literal["dense"]` only — `validate()` raises on anything else; `activation_kind ∈ {silu, situ}`, `situ_gate_beta=4.0, situ_up_beta=25.0`; independent dims `attention_head_dim, kda_head_dim, kda_value_head_dim, kda_decay_rank, mla_latent_size, mla_query_latent_size, mla_key_head_dim, mla_extra_head_dim, mla_value_head_dim` (0 = derive); `kda_short_conv_kernel_size=4`, `kda_gate_lower_bound=-5.0`; `native_feature_dim=3072, native_position_dim=4, native_type_count=8, native_coordinate_frequencies=8, native_loss_reduction ∈ {token_mean, type_balanced}`; `native_bidirectional_refinement` (default False) restricted to `gated_mla` blocks; `mtp_heads=0`; `aux_heads=("flow","grounding","sync")`; `local_window=256, csa_compress_stride=64, hca_compress_stride=1024`. `max_sequence_length` is validated positive but NEVER read by any modeling code.

**Layer schedule**: `block_kind(i)` = pattern[i % len] except last layer forced gated_mla when `force_final_gated_mla`. K3-aligned executable profile `k3_aligned_test_config()`: 5 layers → [kda,kda,kda,gated_mla,gated_mla] = 3 KDA : 2 gated-MLA (README's "3:1" holds only for long schedules; the 93-layer K3-shape test yields 69 KDA : 24 gated-MLA). H=128, I=384, heads=4, head dims 32, kda_decay_rank 32, mla_latent 64, mla_query_latent 64, mla_extra 8, attnres_block_size=2, vocab 4096, SiTU, MTP heads 1, refinement on.

**KDA (`KimiDeltaAttention`)**: q,k,v = Linear(H→n·dk / n·dk / n·dv) → causal depthwise Conv1d(k=4, bias) + SiLU (`CausalDepthwiseShortConv`, Python per-position loop) → q,k L2-normalized. Decay: `decay_up(decay_down(x))` (H→r→n·dk) + per-(head,dim) bias, scaled by exp(per-head log_scale, init U(1,16)), sigmoid, ×gate_lower_bound(−5) → retention = exp(·) ∈ (e⁻⁵,1). β = sigmoid(Linear(H→n)). Update per token: S ← diag(ret)·S + β·k⊗(v − kᵀ(diag(ret)·S)) on state [B,n,dk,dv] (fp32 when input bf16/fp16). Output q·S → `HeadwiseRMSNorm` → × sigmoid(Linear(H→n·dv)) → Linear(n·dv→H). No positional encoding (NoPE). Python loop over sequence positions.

**Gated MLA (`GatedMultiHeadLatentAttention`)**: q: H→ql→RMSNorm→n·(dk+e) (or direct if ql=0); kv: H→(kl+e); RMSNorm(kl); kl→n·(dk+dv); the extra e channels are shared across heads (expand) and concatenated to keys (NoPE). Scores fp32 / sqrt(dk+e), full causal (or supplied [B,T,T] mask); sigmoid(Linear(H→n·dv)) elementwise gate; out Linear(n·dv→H). Reference materializes [B,n,T,T].

**Local / CSA / HCA**: `LocalCausalAttention` (GQA via num_kv_heads, rank-distance window mask applied after full T×T scores); `SparseLatentAttention` = local + mean-pooled block summaries (stride 64 / 1024) attended causally (summary_id ≤ block_id). Optional; not in the K3 schedule.

**Block AttnRes (`DepthAttentionResidual`)**: per token, learned pseudo-query (H, zero-init → uniform weights) softmax over depth sources = completed depth-block outputs + current prefix sum; values un-normalized, keys RMSNormed. Two per block (attention input, FFN input) + one at model output. A completed block is pushed and prefix reset every `attnres_block_size` layers.

**FFN**: dense only. `up: H→2I` (chunk gate/up), `down: I→H`, no bias. SiTU: β_g·tanh(g/β_g)·sigmoid(g)·β_u·tanh(u/β_u) in fp32; SiLU otherwise.

**Native media I/O (encoder-free)**: `native_media.py` — `image_to_native_patches` (unfold P×P, feature = C·P², thwr=(0,y,x,0)); `video_to_native_patches` (tubelet T_t frames × C × P² per token, thwr=(center-time s, y, x, 1/fps), pads last frame); `waveform_to_native_segments` (one token per channel per window, thwr=(center s, 0, window s, channel idx), stride ≤ segment); `ocr_image_to_native_patches`; exact inverses `native_patches_to_image/video`, `native_segments_to_waveform` (overlap-add). `_fit_dim`: pad if feature < feature_dim (lossless), adaptive-avg-pool if larger (flagged lossy; decoders refuse). Type ids image1 video2 audio3 music4 tts5 ocr6. Default spec feature_dim 3072 = 1·3·32·32.
`NativeContinuousMediaBridge`: feature_proj F→H + type_embed + (1+type_feature_scale) + position_proj(4→H) + Fourier(8 freqs 2^k·π, sin/cos → 64→H) + noise_proj(Fourier(σ)16→H→SiLU→H) → RMSNorm → type affine (zero-init) → ×valid. Features scatter_add onto token embeddings at `native_media_indices` (placeholder token 3264 in proofs). `UnifiedNativeMediaEmissionHead`: RMSNorm → type affine → Linear H→F. Loss: MSE per token, `type_balanced` mean-of-per-type-means.
**Flow**: `media/training.py` — x_σ=(1−σ)x₀+σε; velocity target ε−x₀; `sample_joint_av_noise_levels` one base t per sample, shift σ'=s·σ/(1+(s−1)σ) with video 12.0 / audio(3,4,5) 3.0; `rectified_flow_x0_sample` derives v=(x−x̂₀)/max(σ,1e-6) and Euler-integrates a per-token schedule; text/reference rows σ=0 never updated. Target kinds: reconstruction | velocity | x0.
**Refinement mask**: only for velocity/x0 with refinement enabled; media must be a contiguous suffix with trailing padding; cannot co-exist with text labels in one forward (understanding and generation are separate passes); text causal, valid media queries attend text prefix + all valid media, applied only in gated_mla blocks.
**Text loss**: compact valid-token transitions, −100 ignore. MTP heads produce logits only (no MTP loss in forward). Aux heads flow(4)/grounding(4)/sync(1) emitted under `return_aux` only — no loss wiring.
**Cache**: `ChimeraCausalCache` = per-block `KDAState` (recurrent [B,n,dk,dv] + q/k/v conv history [B,width,3]) or `MixerHistory` (ALL past normalized inputs [B,T,H] + valid mask, re-attended every chunk). `runtime_kernel_manifest`: production_ready False, paged_state_implemented False, fused_kernels_implemented False, chunked_prefill_reference_implemented True.
**Ledger** (`build_ledger`): control=max(128,V/64), media=max(256,V/8), grounding=max(128,V/32), sync=max(64,V/64), tool=max(128,V/32), text=remainder.
