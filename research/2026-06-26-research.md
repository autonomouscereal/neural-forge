# 2026-06-26 Research Notes

Scope: 2025-2026 sources only, focused on practical paths for pruning, neuron
merging, model expansion, domain ability expansion, native multimodal expansion,
and cross-model merging.

## Compression: pruning plus neuron merging

- DOTResize, "Reducing LLM Width via Discrete Optimal Transport-based Neuron
  Merging" (arXiv:2507.04517), is the closest current match to direct width
  compaction. It treats width reduction as structured pruning plus recombination:
  neurons that would be discarded are merged into survivors using discrete
  optimal transport rather than simply dropped.
- Model Folding, ICLR 2025, is highly relevant for a general toolkit: fold
  structurally similar neurons/channels with clustering and statistics repair
  instead of cutting them.
- Cut Less, Fold More, ICLR 2026, strengthens the same design claim: pruning is
  axis-aligned projection, while folding is a lower-rank projection that often
  preserves function better.
- GRAIL, CPAL 2026, adds a practical no-backprop recovery path after folding or
  pruning using unlabeled calibration, Gram statistics, and ridge least squares.
- Function-aware neuron grouping/pruning work appearing in the 2026 AAAI cycle
  points in the same direction: preserve groups that matter to functions, not
  just weights with large norms.
- Merging Feed-Forward Sublayers, 2025, is a transformer-specific route:
  identify similar FFN sublayers, align neurons, and merge or remove redundant
  feed-forward computation.
- Practical implication: a production LLM version should not only rank units by
  magnitude. It should build per-layer features from input weights, output
  weights, activation statistics, and optionally function/task probes, then merge
  using an assignment/transport solver.

Implemented in this repo:

- deterministic feature clustering for dense hidden units;
- incoming centroid plus outgoing path-sum merging;
- target-parameter width planning.
- merge-first Hugging Face gated FFN width folding with combined SwiGLU
  features;
- residual decoder layer group averaging/folding before layer slots are removed;
- `hf-search-compress`, an automated width/depth merge-first candidate search
  with behavior gates and target-shrink reporting.
- `hf-xfamily-compress`, an integrated cross-family pipeline that transplants
  donor MLP channels first, searches width/depth folds second, optionally
  recovers selected candidates, and promotes only outputs that still pass
  host-baseline behavior gates.
- compressed-parent native vision graft validation: Qwen3 host plus LFM2.5
  donor, 5.28% merge-first compression, frozen parent, and raw-patch graft
  training to 100% exact synthetic VQA accuracy.

Next compression step:

- add calibration-data activation features;
- add GRAIL-style ridge/statistics compensation after each layer surgery;
- add an optimal-transport merge backend;
- add transformer adapters for MLP intermediate dimensions and attention heads.
- add LLM pruning baselines from 2SSP/Putri-style structured FFN/head surgery.

## Compression as a distillation replacement

The current viable path is "surgery first, small recovery later":

- prune/merge into the target dense shape;
- run calibration or short continued training to recover distribution shift;
- optionally distill only for the final recovery stage, not as the main transfer
  mechanism.

The important distinction is that pruning/merging gives an actual smaller dense
model immediately. Distillation teaches a separate model and pays most of the
training cost. The strongest current path is using merge-aware structured
compression to replace most of that cost, then using light tuning where needed.
Current production examples still often pair pruning with distillation, so this
repo treats "replace most distillation cost" as the realistic target, not "never
train again at any compression ratio."

## Expansion

The practical model-growth family is function-preserving expansion:

- width growth by duplicating neurons and dividing outgoing weights among copies;
- depth growth by inserting identity or near-identity residual blocks;
- continued pretraining with light perturbation or layer-specific learning rates
  so the new capacity becomes useful instead of remaining a clone.
- Deep Progressive Training / zero-one-layer expansion, 2025, provides a current
  depth-growth recipe: new layers are initialized as zero/identity residual
  behavior, optimizer state is migrated, and learning rates are re-warmed.
- SPARKLING, 2026, is the current width-growth signal: preserve activation RMS
  scale, break copy symmetry with asymmetric optimizer reset, and use LR rewarm.
- Warm-start scaling work in 2026 suggests 2x growth is the most reliable
  default regime when compute budget is constrained.
- LOIRE, ICLR 2025, frames PLM growth as composable function-preserving
  operators with preservation checks.
- ADEPT, ICLR 2026, points toward domain-adaptive expansion: grow or unfreeze
  function-aware areas instead of uniformly expanding every layer.

Implemented in this repo:

- Net2Wider-style hidden-layer expansion with exact output preservation when
  noise is zero;
- ReLU identity depth insertion, exact for nonnegative post-ReLU activations.

Next expansion step:

- transformer block duplication/interleaving;
- residual scaling for near-identity transformer layers;
- vocabulary/embedding expansion tools.
- optimizer-state migration and per-parameter LR rewarm policies.
- saliency-guided domain expansion with retention evals.

## New-domain and native multimodal ability expansion

Current native multimodal work in 2025-2026 supports the user's premise:
unified token streams and early-fusion training can process image, video, audio,
and text without permanently relying on separate frozen modality towers as the
core design. Current examples include native multimodal next-token systems such
as Emu3/Emu3.5-style unified token prediction, Qwen3-Omni's end-to-end omni
direction, Gemma 3n-style mobile multimodal work, and NVIDIA Cosmos world-model
families.
- ICCV 2025 scaling-law work for native multimodal models reports no inherent
  disadvantage for early-fusion native training versus late-fusion encoder plus
  LLM designs.
- NEO / From Pixels to Words is a practical encoder-free VLM target: lightweight
  patch embeddings and word embeddings feed a monolithic decoder, with native
  positional handling and staged end-to-end training.
- Tokenizer-free work such as H-Net, ByteFlow, and HAT suggests raw byte/chunk
  backends should be a first-class experimental ability-expansion route.

Practical implication for this toolkit:

- model ability expansion needs embedding/vocabulary expansion and data-mixture
  scheduling, not only hidden-layer shape surgery;
- raw or tokenized modality streams can be represented as added vocabulary rows
  or input-channel projections, then trained through the same backbone;
- shape surgery can prepare capacity before the domain expansion run.

Implemented in this repo:

- `native-vlm-demo`: a tiny single-transformer raw-patch plus text-token
  sandbox for end-to-end synthetic vision/text learning;
- `hf-vision-graft`: a real HF causal LM parent receives raw image patch
  embeddings before text tokens and trains a small patch projection with
  behavior reports.

## Cross-model merging

The practical current path is staged:

1. Normalize architecture metadata.
2. Resize each source into a common target shape.
3. Align permutable hidden axes.
4. Merge with average, SLERP, or signed/delta-based methods.
5. Run calibration or light tuning if the source models are far apart.

Useful 2025-2026 merge directions:

- Task arithmetic remains a reliable modern LLM baseline when source checkpoints
  share a base.
- `mergekit` is the clearest production reference for same-shape and delta-based
  LLM merges.
- Model Fusion via Retrofitting, 2025, directly supports different-width fusion
  using Hungarian matching when widths align and clustering when they do not.
- Chain of Merges, 2025, shows why sequential activation-stat recomputation
  matters: merging an early layer changes downstream distributions.
- RegMean++ and output-space projection work in 2025-2026 point toward ridge or
  convex output-space refits as a practical recovery stage.

Implemented in this repo:

- resize-to-target for same-depth dense models with different widths;
- greedy cosine hidden-unit alignment;
- weighted average and SLERP merge.
- same-shape Hugging Face task arithmetic, `base + alpha * (tuned - base)`,
  with alpha sweeps and behavior gates.
- cross-family MLP-channel transplant that keeps a host runtime, learns a
  shared-token hidden projection, aligns donor channels to host channels, and
  merges donor signal into host MLP weights. Current adapters cover
  Qwen/Llama-style gated MLPs, LFM2.5 `feed_forward.w1/w3/w2`, and
  GPT-NeoX/Pythia dense MLPs.
- activation-calibrated cross-family channel assignment. Calibration prompts
  are run independently through host and donor; each MLP channel is represented
  by per-prompt response summaries, then assigned by activation correlation or
  a hybrid of activation and weight-cosine features.
- similarity-scaled per-layer donor alpha. Each layer can now report assignment
  similarity and scale the donor blend up or down instead of using one global
  alpha everywhere.
- integrated cross-family MLP recovery sweeps that run short same-tokenizer
  host-to-candidate recovery, evaluate the recovered checkpoint, and gate it
  against the original host baseline.
- recovery calibration file loading for plain text and JSONL instruction rows,
  including the curated Omnicoder shard format on the AI share.

Latest 4B donor result:

- `Qwen/Qwen3-4B-Base` -> `EleutherAI/pythia-160m` was shape-valid at roughly
  `24.78x` donor-to-target compression, but current cross-tokenizer MLP folding
  and short curated recovery did not lift behavior above Pythia host level.
- `Qwen/Qwen3-4B-Base` -> `HuggingFaceTB/SmolLM2-135M` was shape-valid at
  roughly `29.90x` donor-to-target compression. The full benchmark-suite slice
  showed the folded model stayed at host level; LM-only recovery improved
  ARC-Easy by the same amount on both folded and host-control models, so the
  improvement came from recovery data rather than donor transfer.
- `Qwen/Qwen3-4B-Base` -> `Qwen/Qwen3-0.6B-Base` same-tokenizer control gave a
  small held-out PPL improvement at `alpha=0.001`, but did not move the
  external ARC-Easy/HellaSwag slice. Donor-teacher recovery reduced training
  loss but worsened held-out PPL.
- First activation-hybrid smoke on `Qwen/Qwen3-4B-Base` -> SmolLM2-135M ran
  end-to-end with 8 calibration texts and a 128/256 channel budget. It passed
  the host gate and improved the lightweight PPL probe versus matched
  weight-cosine (`347.377` vs `348.631`), but remains a smoke result until
  full benchmark/recovery runs show donor capability transfer.
- Correction to validation practice: PPL-only comparisons are insufficient.
  Every real-model surgery claim now needs benchmark-suite task scores and
  generation/coherence checks for host, donor, and edited artifacts.
- Correction to target validation: planting into an already trained host is not
  enough evidence. The toolkit now has `hf-random-init` so donor folding can be
  tested against a blank target architecture with random base weights.
- Benchmark slice after activation-hybrid and similarity-scaled layer alpha:
  ARC-Easy, HellaSwag, PIQA, and Winogrande all stayed exactly at SmolLM2 host
  level for the folded artifacts, while Qwen3-4B was clearly higher. The
  layer-alpha fold lowered PPL but failed generation health due repetition,
  proving that PPL improvement alone can be anti-signal for this objective.
- Blank-target control: `hf-random-init` produced an untrained
  SmolLM2-135M-shaped target and Qwen3-4B was folded into it at roughly `29.90x`
  donor-to-target compression. The folded random target stayed exactly at the
  random target's ARC-Easy, HellaSwag, PIQA, and Winogrande scores, choice
  accuracy stayed `0.00`, and strict generation relevance failed. This proves
  current tiny-alpha cross-family MLP/vocab transplant is only shape-valid for
  blank targets; it is not a capability-transfer path.
- Donor-projected blank initialization now folds donor state-dict tensors
  directly into a target config shape. On Qwen3-4B -> blank SmolLM2-135M, it
  initialized `270` layer tensors plus `30,000` shared embedding/head rows.
  Mean-fold projection moved some benchmark numbers over the random target
  (`ARC-Easy norm 0.22 -> 0.30`, `HellaSwag norm 0.30 -> 0.32`, Winogrande
  `0.46 -> 0.64`) and lowered PPL, but manual generations collapsed into
  repeated tokens and strict generation relevance failed. RMS-fold did not
  improve the run. This is weak evidence of donor structure transfer, not a
  coherent compressed model yet.
- Activation-weighted donor folding was added after more research into 2025-2026
  activation-aware width compression. It collects donor residual and MLP
  activation magnitudes on calibration text and folds source dimensions into
  target bins by activation importance. On the same Qwen3-4B -> blank
  SmolLM2-135M run, it improved PIQA over the random target (`0.56 / 0.58 ->
  0.60 / 0.62`) and slightly lifted Winogrande (`0.46 -> 0.52`), but worsened
  PPL relative to plain mean-fold and still produced repeated-token generations.
  Conclusion: activation ranking changes the fold signal, but it is not enough
  without output reconstruction.

Research implication:

- DOTResize-style discrete optimal transport is a better match for neuron
  merging than hard rank bins: it treats width reduction as an assignment and
  mass-transport problem rather than pruning.
- GRAIL/post-hoc linear reconstruction is the best next practical direction:
  fold first, then fit small calibration-based linear compensation maps so each
  compressed block reproduces the donor block output.
- Chain/sequential merge results imply activations should be recomputed after
  each folded layer, because folding an early block changes downstream
  distributions.
- Activation variance and covariance methods point toward covariance-weighted
  folding/reconstruction rather than scalar mean activation alone.

Additional activation-method search:

- GRAIL, 2026, is the highest-value implementation target. It applies after
  pruning or folding, collects calibration activations, solves a Gram/ridge
  linear reconstruction map, and absorbs that map into the consumer projection.
  That directly targets the repeated-token collapse seen after blank-target
  folding without needing labels or backprop.
- DOTResize, 2025 with 2026 revision, is the better fold-map target. It uses
  activation-signature distances and entropy-regularized transport so removed
  neurons are redistributed into retained/folded width instead of discarded or
  rank-bucketed.
- PGSVD, 2025 with 2026 revision, ALS-ActLR, 2025, and AIR, 2026, are the best
  fallback family when structural folding is too destructive. They optimize
  activation-weighted reconstruction error such as `||X(W - UV)||` rather than
  raw weight error.
- CoSpaDi, 2025, and ROCKET, 2026, suggest a higher-upside dictionary/sparse
  reconstruction path, but the runtime story is more invasive than dense ridge
  compensation.
- TARDIS, 2025, and SubFit / FFN sublayer merging, 2026, are later-stage
  options for folding frequent linear ranges or replacing whole submodules with
  fitted residual bypasses.

Implementation ranking:

1. GRAIL-style ridge/Gram post-fold reconstruction.
2. DOTResize-style activation-distance or OT fold maps.
3. Activation-aware SVD / ALS fallback for layers where folding fails.
4. Sequential layerwise recalibration harness with activations recomputed after
   each repaired layer.

Implementation note after first reconstruction probe:

- The first `hf-reconstruct-folded` pass implements the GRAIL-style mechanics
  for same-tokenizer depth folds: collect calibration activations, solve
  ridge/Gram maps, absorb them into downstream attention/MLP consumer
  projections, and optionally blend the map with identity.
- On SmolLM2-135M layer fold `13+14`, this reduced local downstream activation
  error strongly, but the strongest local fits worsened behavior. A damped
  reconstruction (`ridge=0.01`, `alpha=0.25`) was less destructive and slightly
  improved one external slice metric, but still failed generation/choice gates.
- Practical implication: do not promote candidates on local reconstruction
  error alone. The next compensation target should reconstruct block outputs or
  the folded survivor block's internals directly, then select by held-out
  generation health plus external task slices.
