Here's a Python function that ensures **order** (first-seen) while **remaining** (hundreds of unique) values are removed:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.add item
            unique_items.add(item)
    return unique_items
```

### Time Complexity:
- **O(n)** where `n` is the number of items. Each item is processed once, and set operations (adds) are O(1).

### Expl Explained:
- **` seen`**: maintains a set of items that have been seen so far.
- **` unique_items`**: keeps track of the **hundreds** of unique items (order) that have been added.
- **O(n)** time complexity because each item is checked once.

### short example:
```python
items = [1, 2, 3, 4, 5]
result = unique_in_order(items)
print(result)  # output: [1, 2, 3, 4, 5]
```

This function ensures **order** while **remaining** values are removed, as required.
