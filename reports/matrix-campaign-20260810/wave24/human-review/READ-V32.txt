Here's a Python function that uses a set to remove duplicates while preserving the first-seen order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.additem()
            unique_items.additem()
    return list(unique_items)
```

**Time Complexity:** O(n), where n is the number of items in the input list. This is because each item is processed once, and set operations (addition and membership testing) take constant time on average.

**Example:**

```python
print(unique_in_order([1, 2, 3, 2, 4, 5]))  # [1, 2, 3, 4, 5]
```

This function efficiently filters out repeated items while maintaining the order of first appearance.
