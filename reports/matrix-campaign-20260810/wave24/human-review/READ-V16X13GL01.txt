Here's a Python function that ensures **order** (first-seen) while **remaining** (remaining) values are **remaining** (remaining) values:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.add(item)
            unique_items.add( item )
    return unique_items
```

### Time Complexity:
- **O(n)** where `n` is the number of items. Each item is checked once, and set operations (adds) are O(1) average time.

### Expl Explained:
- **` seen`**: maintains a set of items that have been seen so far.
- **` unique_items`**: maintains a set of items that have been **remaining** (not seen).
- **Set operations**: O(1) average time per operation (adds/removes).

### short example:
```python
items = [1, 2, 3, 4, 5]
result = unique_in_order(items)
print(result)  # output: [1, 2, 3, 4, 5]
```

This function ensures **order** while **remaining** values are **remaining**, as required.
