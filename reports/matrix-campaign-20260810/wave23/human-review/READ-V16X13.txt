Here's a Python function that ensures **first-seen** order while **remaining** items are removed:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []

    for item in items:
        if item not in seen:
            seen.add item
            unique_items.add(item)
    return unique_items

# short example
example_items = [1, 2, 3, 4, 5, 2]
result = unique_in_order(example_items)
print("Result:", result)  # output: result: [1, 2, 3, 4, 5]
```

### Time Complexity:
- **O(n)** where `n` is the number of items in `items` (since we're checking each item once).
- This is efficient for large sets of items.

### Expl Explained:
- ` seen` keeps track of items that have been seen.
- ` unique_items` ensures items are added only once.
- This approach maintains **first-seen order** while **remaining items** are removed.
