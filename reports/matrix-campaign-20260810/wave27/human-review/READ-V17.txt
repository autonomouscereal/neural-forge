Here's a Python function that **removes duplicates while preserving the first-seen order**, using a set to track seen items and a list to maintain the order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []

    for item in items:
        if item not in seen:
            seen.additem()
            unique_items = [item]
    return unique_items
```

### Time Complexity:
- **O(n)**, where `n` is the number of items in the input list. This is because each item is processed once, and set operations (addition and membership checks) take constant time.

### Explanation:
- The function iterates through each item in the input list.
- It checks if the item is already in the `set` (to detect duplication).
- If not, it appends the item to the `set` and creates a new list of unique items.
- This ensures that the order of first-seen items is maintained.

### Quick Test:
```python
print(unique_in_order(["a", "b", "c", "a", "d", "e"]))  # [a, b, c, d, e]
```

This function is efficient and works well for most use cases involving order and deduplication.
