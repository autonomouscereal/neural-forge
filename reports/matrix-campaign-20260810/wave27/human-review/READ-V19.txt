3. **Tidal Heating**:  
   The Sun’s heat causes the planet’s surface to warm up and cool down slightly, creating temperature differences between the day and night sides. This difference in heating leads to wind patterns and weather changes, which are part of the seasons.

4. **Atmospheric and Oceanic Changes**:  
   The tilt also affects how sunlight is distributed across the planet’s surface. For example, the tilt causes the Northern and Southern hemispheres to receive different amounts of sunlight, leading to distinct seasons.

While Earth’s distance from the Sun does influence temperature and weather, the **tilt** of its axis is the primary driver of seasons. The Sun’s energy is more intense at the equinoxes (where the tilt is highest), and this variation in sunlight causes the seasons to shift. Here's a Python function that **removes duplicates while preserving the first-seen order**, using a set to track seen items and a list to maintain the order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []

    for item in items:
        if item not in seen:
            seen.additem()
            unique_items.append(item)

    return unique_items
```

### Time Complexity:
- **O(n)**, where `n` is the number of items in the input list. Each item is processed once, and set operations (addition and membership checks) are average O(1).

### Short Explanation:
- The function iterates through each item in the input list.
- It checks if the item is already in the `set` (to detect duplication).
- If not, it adds the item to the `set` and appends it to the `list` of unique items.

This approach ensures that the order of first-seen items is maintained while keeping the list of unique items in order.
