Sure! Here's a Python function that **remains in order** while **remaining** as **first-seen** values:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []

    for item in items:
        if item not in seen:
            unique_items = [item]
            seen = set()
    return unique_items
```

### Time Complexity:
- **O(len(items))**: Since we're checking each item once and updating the ` seen` set, this is O(len(items)).

### Expl Explained:
- ` seen` keeps track of items that have been seen.
- For each item in `items`:
  - If it hasn't been seen yet, add it to ` unique_items`.
  - Mark it as seen.
- This ensures that **first-seen** items are **not** included in ` unique_items` (since they were added first).

### Quick example:
```python
print( unique_in_order( [1,2,3,4,5] ) )  # [1,2,3,4]
```
