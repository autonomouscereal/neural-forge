Here's a Python function that **removes duplicates while preserving the first-seen order**, using a set to track seen items and a list to maintain the order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []

    for item in items:
        if item not in seen:
            seen.additem()
            unique_items.append(item)

    return unique_items
```

### Time Complexity:
- **O(n)**, where `n` is the number of items in the input list. Each item is processed once, and set operations (addition and membership checks) are average O(1).

### Explanation:
- The function iterates through each item in the input list.
- It uses a set `seen` to track items that have already been added to the result list.
- It appends each new item to the result list only if it hasn't been seen before.
- This ensures that the result maintains the first-seen order.

### Quick Test:
```python
print(unique_in_order(["a", "b", "c", "a", "d", "e"]))  # [a, b, c, d, e]
```

This function is efficient and works well for most practical use cases.
