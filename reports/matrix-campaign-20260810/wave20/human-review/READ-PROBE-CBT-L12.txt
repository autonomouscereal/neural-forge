Here's a Python function that removes duplicates while preserving the first-seen order of elements, and it works with hashable values.

```python
def unique_in_order(items):
    seen = set()
    unique = []
    for item in items:
        if item not in seen:
            seen.add(item)
            unique.append(item)
    return ''.join(unique)
```

**Time Complexity:** O(n), where n is the number of elements in the input list. This is because we iterate through the list once and perform constant-time operations for each element.

**Example:**

```python
print(unique_in_order([1, 2, 3, 2, 1]))  # Output: "1, 2, 3"
```

This function works by using a set to keep track of elements we've seen so far, and a list to collect the unique elements in the order they first appeared.
