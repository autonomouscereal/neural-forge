---  9 coding-deduplicate [complete] 605 chars, 569 collapsed
```python
def unique_in_order(items):
    seen = set()
    for item in items:
        if item not in seen:
            seen.add(item)
    return sorted(items)
```

This function works by iterating through each item in the input list, and adding each item to a set to avoid duplicates. The time complexity is O(n) because each item is processed once, and the space complexity is O(n) for storing the set of seen items.

Example:
```python
print(unique_in_order([1, 2, 3, 4, 5]))  # Output: 1
```

This function is efficient and has a time complexity of O(n) because it only iterates through each item once.
