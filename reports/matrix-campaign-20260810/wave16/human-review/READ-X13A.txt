---  9 coding-deduplicate [complete] 788 chars, 735 collapsed
Here is a Python function that removes duplicates while preserving first-seen order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []
    for item in items:
        if item not in seen:
            unique_items.append(item)
            seen.add(item)
    return unique_items
```

Time complexity: O(n), where n is the number of items in `items`. This is because we iterating through `items` once and performing operations on `seen` and `unique_items` are both O(n) operations.

Example usage:
```python
items = [1, 2, 3, 4, 5]
print(unique_in_order(items))  # Output: [1, 2, 3, 4, 5]
```

This function uses a Python `set` to store items, which inherently preserves their order. The `set` operation has O(n) time complexity, making it efficient for this task.
