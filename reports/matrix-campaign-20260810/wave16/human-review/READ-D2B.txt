---  9 coding-deduplicate [complete] 603 chars, 577 collapsed
Here's a Python function that removes duplicates while preserving first-seen order using `set` data structure:

```python
def unique_order(items):
    unique = set()
    for item in items:
        unique.add(item)
    return unique
```

**Time Complexity**: O(n)

This function efficiently removes duplicates from a list using `set` operations, which ensures that all elements are sorted and `unique` maintains first-see order.

**Example**: `[1, 2, 3]`

```python
print unique_order([1, 2, 3]) → [1, 2, 3]
```

The `set` operations are O(1) average time complexity, making it efficient for large lists.
