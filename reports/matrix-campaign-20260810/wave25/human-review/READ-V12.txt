Here's a Python function that **removals** duplicates while preserving the **first-seen order** of items:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.additem()
            unique_items.add(item)
    return list(unique_items)
```

### Time Complexity:
- **O(n)**, where `n` is the number of items in the input list. This is because we process each item at most once.

### Explanation:
- We use a set `seen` to track items we've already processed.
- For each item, we check if it's already in `seen`:
  - If not, we add it to both `seen` and `unique_items` (preserve order).
- The final result is a list of unique items in **first-seen order**.

### Quick Test:
```python
print(unique_in_order([]))  # []
print(unique_in_order([]))  # []
print(unique_in_order(("a", "b", "c"))  # ["a", "b", "c"]
```

This function is efficient and works well for most use cases.
