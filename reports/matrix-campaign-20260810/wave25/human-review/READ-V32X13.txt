Here is a Python function that remove duplicated items while preserving first-seen order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = []

    for item in items:
        if item not in seen:
            seen.add item
            unique_items.append item

    return unique_items
```

Time complexity: O(n), where n is the number of items in `items`, since we're performing a linear search through `items` to populate ` seen` and ` unique_items`.

Example usage:
```python
items = [1, 2, 3, 4, 5]
print( unique_in_order(items))  # output: [1, 2, 3, 4, 5]
```

This function uses a Python `set` to efficiently store items, ensuring that each item is only added once. The `set` operation has O(1) time complexity, making it efficient for this task.
