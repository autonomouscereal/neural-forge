```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen = set()
            unique_items = [item]
            seen = set()
    return unique_items
```

### Time Complexity:
- **O(|items|)** — We process each item at most once, and we store each item in a set to track seen items.

---

### **One example**:
```python
print(unique_in_order([1, 2, 3, 2, 4, 5]))  # [1, 2, 3, 4, 5]
```

This function works by:
- Storing each item in a set to avoid reprocessing.
- Storing the first time an item is seen, so it's added to the result set.
- This ensures that the first time an item is seen, it's added to the result set.
