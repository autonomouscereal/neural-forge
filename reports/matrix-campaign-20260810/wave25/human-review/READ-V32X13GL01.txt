Here is a Python function that removes duplicates while preserving first-seen order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.add item
            unique_items.add(item)
    return unique_items
```

Time complexity: O(n), where n is the number of items in `items`, since we are performing a linear search through `items` to populate ` seen` and ` unique_items` sets.

Example usage:

```python
items = [1, 2, 3, 4, 5, 6]
print( unique_in_order(items))  # output: [1, 2, 3, 4, 5, 6]
```

This function uses Python's `set` data structure, which provides efficient membership testing and operations, making it ideal for this task.
