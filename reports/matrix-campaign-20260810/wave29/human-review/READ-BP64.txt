---  9 coding-deduplicate [complete] 807 chars, 754 collapsed
Here's a Python function that ensures **duplicates are removed while preserving the order** of elements:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.add item
            unique_items.add(item)
    return unique_items
```

### Time Complexity:
- **O(n)** where `n` is the number of items in `items` (since we iterating through each item once).
- **O(n)** for building the ` seen` set (also O(n)).
- **O(n)** for iterating through `items` (also O(n).

### Short example:
```python
items = [1, 2, 3, 4, 5]
result = unique_in_order(items)
print(result)  # output: [1, 2, 3, 4, 5]
```

This function effectively maintains order while automatically handling **duplicates** by keeping track of seen elements.
