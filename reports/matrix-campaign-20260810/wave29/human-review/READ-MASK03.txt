Here's a Python function that ensures **order** (first-seen) while **remaining** (hundreds) of **duplicates** are removed:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.add item
            unique_items.add item
    return unique_items
```

### Time Complexity:
- **O(n)** where `n` is the number of items. Each item is processed once, and set operations (adds/remove) are O(1).

### Short example:
```python
items = [1, 2, 3, 4, 5]
result = unique_in_order(items)
print(result)  # output: [1, 2, 3, 4, 5]
```

This function maintains **order** by keeping track of **which** items have been seen, while **remaining** items are removed in order.
