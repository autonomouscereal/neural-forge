Here's a Python function that ensures **order** (first-seen) while **remaining** (remaining) values are **remaining** (preserved). It uses a **permuted** algorithm to maintain order:

```python
def unique_in_order(items):
    seen = set()
    unique_items = set()
    for item in items:
        if item not in seen:
            seen.add item
            unique_items.add(item)
    return unique_items
```

### Time Complexity:
- **O(n)** where `n` is the number of items. Each item is checked once, and set operations (adds) are O(1).

### Short example:
```python
items = [1, 2, 3, 4, 5]
result = unique_in_order(items)
print(result)  # output: [1, 2, 3, 4, 5]
```

### Expl Explained:
- **` seen`**: keeps track of items that have been seen.
- **` unique_items`**: keeps track of items that are **remaining** (not seen).
- **` set()`**: ensures **order** is maintained (since ` set` in Python is unicycles).

This approach ensures both **order** and **remaining** values are maintained while handling **hundreds** of items.
